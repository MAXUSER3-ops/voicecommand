CHAT & ACCESSIBILITY UPDATE

What’s new in version 1.11.0

This update adds clearer history controls, refreshed chat styling, model download progress, and a helpful WebGPU compatibility message.

  • Delete the current chat history from this device and, when signed in, the synced account.
  • See model-download progress and a percentage while on-device AI loads.
  • Astro, Macro, and Chato now explain their conversation styles more clearly.
  • If WebGPU is unavailable, VoiceCommand explains how to try a supported browser or PC/laptop.
  • The chat, controls, and messages have a refreshed modern look.
Recent updates · versions 1.9.0–1.8.0

Version 1.9.0

  • Google sign-in and cross-device chat text sync were added through Supabase. Guest mode and its browser auto-save remain available.
  • The VoiceCommand title was enlarged and the footer changed to Early testing.

Version 1.8.0

  • Phone layout controls were enlarged and the message composer simplified.
  • Chat replies use a smaller model and shorter response limit to help them arrive faster.
  • Replies were tuned for brief, natural back-and-forth conversations.
  • Astro, Macro, and Chato modes were added, along with Sunset, Forest, Rose, and Slate backgrounds.
  • Autosave, the orange save indicator, and the temporary two-minute profanity timeout were added.

You can reopen this update log from the entry screen any time.
